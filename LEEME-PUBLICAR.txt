PUBLICAR EN GITHUB PAGES  ·  encarrila.github.io/barmitzvauri
================================================================

1. github.com  ->  New repository
     Nombre: barmitzvauri
     Público
     Create repository

2. En el repo vacío: "uploading an existing file"
     Arrastrá TODO lo que está dentro de esta carpeta
     (index.html, support.js, .nojekyll y la carpeta musica).
     OJO: los archivos sueltos, no la carpeta "publicar" entera.
     Commit changes.

3. Settings -> Pages
     Source: Deploy from a branch
     Branch: main   /  (root)   -> Save

4. Esperá 1-2 minutos. Queda en:
     https://encarrila.github.io/barmitzvauri/


ANTES DE MANDAR LOS LINKS
================================================================

[x] ENDPOINT del formulario  ->  YA ESTÁ PUESTO
    Las confirmaciones caen en la hoja "RSVP" de tu planilla.
    Probalo después de publicar: llená el formulario con tu nombre
    y fijate que aparezca la fila.

[ ] Música (opcional)
    Poné tu mp3 en musica/cancion.mp3

[ ] Favicon (opcional)
    Poné un png en fotos/favicon.png (creá la carpeta fotos)
